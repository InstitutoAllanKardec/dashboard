# Dashboard de Campanhas de Marketing

## Instituto Espírita de Estudos Allan Kardec

Dashboard interativo para visualização e análise de métricas de campanhas de marketing digital.

### Funcionalidades

- **Funil de Marketing**: Visualização clara do caminho do cliente (Alcance → Cliques → Visitas → Engajamento)
- **Métricas Chave**: Custo por visita, taxa de clique, taxa de visita e tempo de engajamento
- **Análise de Performance**: Comentários gerais sobre o desempenho das campanhas
- **Gráficos Interativos**: Visualizações em tempo real com Chart.js

### Dados Inclusos

- Período: 19 a 26 de Outubro de 2025
- Campanhas: Google Ads Performance Max
- Fonte de Dados: Google Ads e Google Analytics 4

### Como Usar

1. Abra o arquivo `index.html` em seu navegador
2. Explore o funil de marketing
3. Analise as métricas chave
4. Revise os comentários de performance

### Tecnologias

- HTML5
- CSS3
- JavaScript
- Chart.js (para gráficos)
